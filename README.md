## Контрольные вопросы
1. Потому что имя компьютера не хранится в самой программе — оно запрашивается у операционной системы во время выполнения. В коде написано только обращение Environment.MachineName, а конкретное значение возвращает Windows из своих системных настроек.
2. ОС выступает посредником между программой и оборудованием.
3. 64 битная система способна адресовать больше оперативной памяти, чем 32 битная
4. Environment.ProcessorCount показывает число логических процессоров, которые видит операционная система, с физическими ядрами не совпадает
5. Память процесса отличается тем, что это объём физической памяти, который используется конкретным процессом. А вся оперативка это общий ресурс распределнный на всё.
6. Потому что значения берутся не из кода, а из окружения, в котором запускается программа.
